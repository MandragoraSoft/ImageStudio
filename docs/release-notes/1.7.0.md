# ImageStudio 1.7.0: rozmowa AI i wygodniejsza edycja promptów

## Nowe
- **Edytor promptów:** osobne pola SYSTEM, REQUEST i negatywny prompt w generowaniu, edycji i wideo. Szerokość panelu wspomagania można zmieniać przeciągając separator.
- **Rozmowa AI:** dopracuj prompt w rozmowie z modelem i dostępnymi narzędziami, a następnie wczytaj propozycję do edytora. Możesz wznowić rozmowę po zamknięciu edytora lub rozpocząć nową bez zmiany promptu. W Ustawieniach wybierzesz zapis na dysku, w pamięci aplikacji albo brak zapisu.
- **Analiza obrazów:** model może opisać bieżące załączniki edycji lub wideo i wykorzystać opis w dalszej rozmowie.
- **Żądania sieciowe:** stopka pokazuje aktywne żądania i umożliwia anulowanie wybranego.
- **Cache dostawcy:** czat wspomaga wykorzystanie pamięci podręcznej oficjalnych API OpenAI i OpenRouter oraz pokazuje liczbę tokenów odczytanych z cache, jeśli dostawca ją zwróci.

## Poprawki
- Czat nie wysyła narzędzi do modeli bez potwierdzonej obsługi. Załączniki pozostają w szkicu, jeśli model nie przyjmuje obrazów.
- Analiza nie dołącza ponownie obrazów usuniętych z bieżących załączników, nawet po wznowieniu rozmowy.
- Jednorazowa przebudowa promptu waliduje strukturę odpowiedzi przed zmianą pól.

## Znane ograniczenia
- Dostępność negatywnego promptu zależy od modelu i dostawcy. Jeśli nie potwierdzają obsługi, aplikacja ostrzega i nie wysyła go jako parametru.
- Narzędzia są wyłączone również wtedy, gdy katalog nie potwierdza ich obsługi; obecnie dotyczy to także modeli z katalogów OpenAI i ChatGPT.
- Szkic wiadomości i oczekujące załączniki rozmowy edytora nie są przywracane po zamknięciu okna. Rozmowy otwierane z zestawów nie są zapisywane. Zmiana trybu zapisu nie usuwa wcześniejszych plików rozmów.
- Cache działa po stronie dostawcy; trafienie nie jest gwarantowane, a u niektórych dostawców zapis do cache może być płatny.
- OpenRouter nadal nie obsługuje mowy ani rozpoznawania mowy. Wtyczki OneDrive i Google Drive nie były sprawdzane na prawdziwych kontach.

## Który plik pobrać
- `ImageStudio-1.7.0-Setup.exe`: zalecany instalator; aktualizuje poprzednią wersję w miejscu i zachowuje dane użytkownika.
- `ImageStudio-1.7.0-win-x64-samodzielna.exe`: jeden plik z wbudowanym .NET, bez instalacji.
- `ImageStudio-1.7.0-win-x64-wymaga-dotnet.exe`: mniejszy plik, wymaga .NET 10 Desktop i ASP.NET Core Runtime.

Pliki nie są podpisane certyfikatem, więc Windows SmartScreen może pokazać ostrzeżenie.
