# ImageStudio 1.6.0: archiwum, miniatury i informacje o aplikacji

## Nowe
- **Archiwum galerii:** przenoszenie lokalnych obrazów i wideo do archiwum z menu pod prawym przyciskiem. Folder archiwum można wybrać w Ustawieniach → Aplikacja.
- **Obrazy wejściowe w edycji:** wszystkie załączone obrazy są widoczne jako miniatury. Kolejność można zmieniać przeciąganiem lub przyciskami; pierwszy obraz pozostaje podstawowy i określa proporcje.
- **Pomoc:** nowe okno z informacjami o aplikacji i numerem wersji.

## Poprawki
- Zabezpieczono oznaczanie pochodzenia wyniku podczas zmiany magazynu w trakcie zapisu.
- Usunięto ostrzeżenie kompilacji dotyczące panelu edycji.

## Znane ograniczenia
- Archiwizacja obejmuje obrazy i wideo z aktualnie skonfigurowanych folderów magazynu lokalnego, nie wyniki z chmury. Starsze wpisy o nieznanym pochodzeniu wymagają potwierdzenia, że plik jest lokalny.
- Istniejący plik o tej samej nazwie w archiwum nie zostanie nadpisany: trzeba najpierw zmienić jego nazwę lub wybrać inny folder.
- OpenRouter nadal nie obsługuje mowy ani rozpoznawania mowy. Wtyczki OneDrive i Google Drive nie były sprawdzane na prawdziwych kontach.

## Który plik pobrać
- `ImageStudio-1.6.0-Setup.exe`: zalecany instalator; aktualizuje poprzednią wersję w miejscu i zachowuje dane użytkownika.
- `ImageStudio-1.6.0-win-x64-samodzielna.exe`: jeden plik z wbudowanym .NET, bez instalacji.
- `ImageStudio-1.6.0-win-x64-wymaga-dotnet.exe`: mniejszy plik, wymaga .NET 10 Desktop i ASP.NET Core Runtime.

Pliki nie są podpisane certyfikatem, więc Windows SmartScreen może pokazać ostrzeżenie.
