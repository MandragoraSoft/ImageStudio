# ImageStudio 1.8.0: zasobnik i czyszczenie danych

## Nowe
- **Jedna instancja:** ponowne uruchomienie przywraca istniejące okno aplikacji w tej samej sesji Windows.
- **Zasobnik systemowy:** w Ustawieniach → Aplikacja można włączyć ukrywanie okna po zamknięciu. Ikona pozwala przywrócić okno albo zakończyć aplikację; opcja jest domyślnie wyłączona.
- **Selektywne czyszczenie danych:** w Ustawieniach → Aplikacja wybierzesz kategorie danych do usunięcia i potwierdzisz operację. Logowania i klucze dostawców są domyślnie odznaczone. Czyszczenie indeksów galerii nie usuwa plików multimedialnych ani plików w chmurze.

## Poprawki
- Rozmowy AI edytorów generowania, edycji i wideo korzystają z odrębnych historii i kontekstu bieżącego edytora. Wczytanie zestawu czyści historię przebudowy tylko właściwej zakładki.

## Znane ograniczenia
- Starsze rozmowy edytora promptów mogły zawierać dane innych zakładek. Pozostają na dysku, ale nie są wznawiane; nowe rozmowy zaczynają się od pustej historii.
- Dla izolacji rozmowa edytora nie udostępnia narzędzi plików, pamięci, galerii, zestawów ani zewnętrznych MCP. Zwykły czat zachowuje dotychczasowe narzędzia.
- Czyszczenie jest nieodwracalne, a po jego próbie aplikacja kończy działanie również w razie błędu. Pliki niejednoznacznych zestawów pozostają i są zgłaszane jako błąd; konfiguracja MCP może zawierać tokeny. Zmienne środowiskowe nie są usuwane.
- OpenRouter nadal nie obsługuje mowy ani rozpoznawania mowy. Wtyczki OneDrive i Google Drive nie były sprawdzane na prawdziwych kontach.

## Który plik pobrać
- `ImageStudio-1.8.0-Setup.exe`: zalecany instalator; aktualizuje poprzednią wersję w miejscu i zachowuje dane użytkownika.
- `ImageStudio-1.8.0-win-x64-samodzielna.exe`: jeden plik z wbudowanym .NET, bez instalacji.
- `ImageStudio-1.8.0-win-x64-wymaga-dotnet.exe`: mniejszy plik, wymaga .NET 10 Desktop i ASP.NET Core Runtime.

Pliki nie są podpisane certyfikatem, więc Windows SmartScreen może pokazać ostrzeżenie.
