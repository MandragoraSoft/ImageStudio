# ImageStudio 1.5.0: lepszy czat, narzędzia i zestawy promptów

## Nowe
- **Czat:** wskaźnik wykorzystania kontekstu i limit okna modelu; narzędzia można wyszukiwać, sortować i grupować w profile, a ich zużycie tokenów jest szacowane.
- **Zestawy promptów:** wyszukiwanie, duplikowanie i edycja zapisanych zestawów (model, treść, rozmiar i parametry); wspomaganie AI przy nazwie i opisie, autozapis, proporcje obrazu oraz otwieranie edytora promptów bezpośrednio z zestawu.
- **Edytor promptów:** nowy układ dwukolumnowy i wspólny pasek statusu.
- **Filtr NSFW:** trzy tryby: tylko NSFW, wszystkie modele albo ukrycie NSFW.

## Poprawki
- Wyłączone narzędzia MCP nie są wysyłane do modelu.
- Okno zestawów ostrzega o niezapisanych zmianach przed zamknięciem.
- Naprawiono błąd występujący po zamknięciu przeglądarki modeli.

## Znane ograniczenia
- Obsługa Image API w OpenRouter była sprawdzana tylko w testach automatycznych na atrapach, nie na prawdziwym koncie.
- Dymek czatu przewinięty poza ekran traci zaznaczenie tekstu i stan rozwinięcia sekcji „Rozumowanie”.
- OpenRouter nadal nie obsługuje mowy ani rozpoznawania mowy.
- Wtyczki OneDrive i Google Drive nie były sprawdzane na prawdziwych kontach.

## Który plik pobrać
- `ImageStudio-1.5.0-Setup.exe`: zalecany instalator; aktualizuje poprzednią wersję w miejscu i zachowuje dane użytkownika.
- `ImageStudio-1.5.0-win-x64-samodzielna.exe`: jeden plik z wbudowanym .NET, bez instalacji.
- `ImageStudio-1.5.0-win-x64-wymaga-dotnet.exe`: mniejszy plik, wymaga .NET 10 Desktop i ASP.NET Core Runtime.

Pliki nie są podpisane certyfikatem, więc Windows SmartScreen może pokazać ostrzeżenie.
